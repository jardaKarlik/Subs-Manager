❌ COMMON ISSUES & FIXES:

Issue: "I don't see progress bars or badges"
Fix: Your subscriptions need next_billing_date field set
     Format: "2026-06-05T00:00:00"
     Then refresh browser

Issue: "Colors look wrong"
Fix: Clear cache:
     Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)
     Then hard refresh: Ctrl+Shift+R

Issue: "npm install fails"
Fix: rm -rf node_modules
     npm cache clean --force
     npm install

Issue: "Port 5173 already in use"
Fix: pkill -f vite
     Then npm run dev again

Issue: "Backend not responding"
Fix: 1. Check Terminal 1 shows: Uvicorn running...
     2. Try: http://localhost:8000 in browser
     3. Check for errors in Terminal 1
