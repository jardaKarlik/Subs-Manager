🎨 DESIGN FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🔹 Glass Morphism
     • Frosted glass aesthetic with backdrop blur
     • Semi-transparent overlays with subtle borders
     • Physically-based material simulation (IOR: 2.14)
     • Chromatic aberration & iridescence effects

  🎯 Interactive Elements
     • Mouse parallax tracking on cards
     • Hover lift effect (scale + elevation)
     • Radial glow effect following cursor
     • Shine overlay animations
     • Staggered fade-in on load

  🎨 Color System
     • Deep void black background (#0a0a0c)
     • 11 category-based gradient colors
     • Yellow accent (#ffe600) for CTAs
     • Green (#5fe39a) for active status
     • Purple (#a78bfa) for secondary actions

  📱 Responsive Design
     • 1 column: Mobile
     • 2 columns: Tablet  
     • 3 columns: Desktop
     • 4 columns: Wide screens

  ⚡ Smooth Animations
     • 0.6s slide-up entrance (0.05s stagger)
     • Cubic bezier easing
     • GPU-accelerated transforms
     • 60fps performance target

1️⃣  Navigate to frontend directory:
    cd c:\_dev\subscription_manager\frontend_glass

2️⃣  Install dependencies:
    npm install

3️⃣  Start development server:
    npm run dev

4️⃣  Ensure backend is running:
    python api.py  (in another terminal)

5️⃣  Open in browser:
    http://localhost:5173
